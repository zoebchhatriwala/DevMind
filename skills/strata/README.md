# Strata: Code Visualization for Vibe Coders & Seniors

Visual map of an application designed for vibe coders to understand what AI built without reading code, and for senior engineers to review blast radius and trust boundaries before shipping.

## Activation Triggers
Activates when the user asks:
- *"generate code map"*
- *"visualize this app"* or *"visualize code"*
- *"show me what I built"* or *"what did I actually build?"*
- *"map the architecture"*
- *"strata"* or *"/strata"*
- *"check blast radius"*

## Output
Generates or updates a self-contained, offline interactive HTML map at:
`file://<project-root>/.devmind/strata.html`
